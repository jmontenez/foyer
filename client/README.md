# Client Foyer

Application Flutter Android native et web. L’interface est en français ; les règles métier et le stockage restent dans l’API.

Voir [le guide d’installation](../docs/installation.md) pour Google, Firebase, la signature et les options de compilation. Le client web utilise son origine ; Android utilise `API_URL` ou l’adresse HTTPS saisie dans ses réglages. Aucune écriture hors connexion dans cette version.
